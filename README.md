## What This MVP Is

This MVP is a static/local evidence diagnostic framework for baseline ML model review.

It is designed to show how a stock-evaluation system can organize model diagnostics, evidence, risk checks, and human-review routing without becoming a trading system.

## Engine Universe: What the 77k+ Specs Mean

The 77k+ number does not mean 77k trained models.

It is a generated diagnostic engine-spec universe. It proves that the MVP can manage many model configurations with deterministic IDs, static execution rules, safe skip behavior, and a clear path toward support/stack/risk/evidence governance.

Current generated counts:

- Baseline engine specs: 32,850
- Support engine specs: 22,500
- Stack engine specs: 22,500

These are not performance claims, live trading claims, or profitability claims.

Each baseline engine spec represents a concrete diagnostic configuration such as:

```text
model_key + target + horizon + feature_set + policy
```

Each engine can run independently if matching static evidence exists. If evidence is missing, the engine returns a safe skip instead of fabricating output.

Support and stack engine specs are designed for later layers that combine, compare, or check outputs from baseline diagnostic engines.

## How to Run One Static Engine

```powershell
python -m src.hackaithon_mvp.engine_runtime.engine_runner --engine-id classification.logistic_l2.absolute_direction.h40.feature_set_c.threshold_055
```

This runs a static diagnostic engine lookup.

It does not train a model, run model inference, fetch live data, call provider APIs, or provide a trading recommendation.

## Catalog Policy

Full generated JSONL catalogs are generated artifacts and are not tracked in Git.

The repository tracks:

* generator code
* concise catalog summaries
* a generation manifest
* small sample catalogs

Relevant paths:

```text
catalogs/hackaithon_mvp/catalog_generation_manifest.json
catalogs/hackaithon_mvp/samples/
```

This keeps the MVP codebase lightweight while preserving reproducibility.

## 8-Layer Diagnostic Chain

The current MVP includes the 8-layer diagnostic chain for static diagnostic routing.

Planned layers:

1. Quant Core Engine
2. Scenario Engine
3. Risk Governance Engine

5. Market Context Engine
